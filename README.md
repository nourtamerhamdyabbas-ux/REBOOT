# REBOOT V.1
 - A Retro & Neon style main menu UI & Game
## How To Run The Game?
- To Try the main menu you should open the itch.io link
- here is the link: https://nourtamerhamdyabbas-ux.itch.io/reboot
 
## How To Try the main menu UI?
- After clicking on the itch.io link and the game runs, a retro style animation occurs and a button in the center on the window states "Show Main Menu" click on it and the main menu will appears in the retro style animation.
- You can Message with echo the story narrator, by clicking on the button "Message Echo". After pressing on it the chatting terminal will appear, so you know more about the objectives.
- After pressing on the start button the player will be transfered to the terminal (levels scene). There the player should press on power on button to employ the terminal, and press on command help button for exploring the commands that can be used. If the player type the command ("OPEN LEVEL 01") the system will transfer him to Level 1 page, which involves all the details about the level.
- If the player type the command (LIST LEVELS) he will find that levels 02 and 03 are locked.However, if the player type the commands (OPEN LEVEL 02 or OPEN LEVEL 03), the player will enter the preview mode for the level selected.
- Note: In the preview mode the "initiate mission" button is disabled, as it is a preview mode only. 
- Note: the player can power On/Off the terminal.
- A guidance system is present at the scenes in the main menu that can make the player feel confused.
- There is a scene transition that demostrates the scene loading process, it initiates when the player try to change between scenes.
- When the player enter the settings scene by pressing on the settings button, the player can toggle between two buttons (audio & display), which control the settings of the audio and display. Moreover, after the player make his changes he can apply those changes or reset them.
- When the player enters the guide scene will find buttons for the type of action, after pressing on these buttons an animation will run and the correct key should be used will appear.
- At the last scene the credits scene, the player will find a scroll up credits for everyone contributed to this project.
